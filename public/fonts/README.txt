Drop your licensed brand fonts in this folder, using EXACTLY these file names:

  Brolian-Black.woff2   (or .ttf / .otf)   -> display headings (brochure "Brolian Black")
  Velmont.woff2         (or .ttf / .otf)   -> logo + elegant statements

Until they are added the site falls back to Abril Fatface (display) and Italiana (elegant),
which are bundled automatically. Poppins (incl. Medium Italic) is already bundled.
Convert .ttf/.otf to .woff2 at https://transfonter.org for a smaller download.
